The [API Reference](api.html) documents the complete public surface — every function and hook, with its signature in both TypeScript and ReScript and a minimal runnable example.

From here, the most useful next step is usually to take a small piece of existing state — a form, a filter, a selection — and rewrite it with `tilia` and `useTilia` to feel the difference in how little code the reactive version needs.

### Getting help

Open an issue on the GitHub repository linked in the footer of any page on this site if something in the docs is unclear or the behavior does not match what is described here.
